ProductHub Creator — Paket Upgrade v4
======================================

Isi ZIP ini adalah 7 BERKAS PENGGANTI untuk repo producthub Anda.
Struktur folder di dalam ZIP sama persis dengan struktur repo, jadi
cukup salin seluruh isinya ke folder repo dan pilih "Replace".

  index.html
  admin.html
  assets/css/style.css
  assets/js/ui.js
  assets/js/api.js
  assets/js/landing.js
  assets/js/admin.js

PENTING — assets/js/config.js SENGAJA TIDAK ADA di ZIP ini.
Berkas itu menyimpan GAS_URL Anda, jadi tidak mungkin tertimpa.

URUTAN WAJIB (login PIN mati begitu backend v4 aktif):
  1. Buat Client ID Google        (Tahap A)
  2. Tempel Kode.gs, isi GOOGLE_CLIENT_ID, jalankan upgradeKeV4(),
     Deploy → New version        (Tahap B)
  3. Push berkas ZIP ini          (Tahap C)

Backend (Kode.gs) dikirim TERPISAH di percakapan, bukan di ZIP ini.
